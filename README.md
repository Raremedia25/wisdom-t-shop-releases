# WISDOM T SHOP LTD - app downloads

Installable apps of the WISDOM T SHOP management system. Every release carries:

- `Wisdom-<version>-android.apk` - the Android app (phones and tablets)
- `Wisdom-<version>-Setup.exe` - the Windows program for shop PCs

The newest files are always at the latest release; the system's own Downloads page (https://wisdom-t-shop.onrender.com/apps) links to them.
Signing in needs an account given by the shop administrator; the source code is kept in a private repository.
